## Proyectos destacados

### [AprendizajeIngles](https://github.com/MatiasATorresS/AprendizajeIngles)

Plataforma educativa full stack desplegada para estudiantes de enseñanza media. Incluye autenticación, seguimiento de progreso, panel administrativo y generación de ejercicios mediante IA.

**Stack:** React · Vite · Node.js · Express · MySQL/TiDB · OpenRouter · Vercel · Render  
🔗 [Ver aplicación](https://aprendizaje-ingles.vercel.app/)

### [Análisis de Siniestros de Tránsito en Chile](https://github.com/MatiasATorresS/conaset-siniestros-chile)

Análisis reproducible de **25 años de datos oficiales de CONASET**, con limpieza, exploración y visualizaciones de tendencias temporales, regionales y por tipo de usuario vial.

**Stack:** Python · Pandas · Matplotlib · Seaborn · Jupyter Notebook  
🔗 [Ver notebook en Kaggle](https://www.kaggle.com/code/matiastos/siniestros-de-tr-nsito-en-chile-2000-2024)

### [Scuba Cat](https://github.com/MatiasATorresS/scuba-cat)

Proyecto de visión computacional que detecta gestos frente a la cámara y activa contenido audiovisual en tiempo real.

**Stack:** Python · OpenCV · MediaPipe
